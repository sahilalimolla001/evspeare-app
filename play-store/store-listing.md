# Play Store Listing Draft

## App Name

Ev Speare

## Short Description

Shop EV spare parts with fast fulfilment, secure payment, and live order tracking.

## Full Description

Ev Speare helps customers browse and order EV spare parts from a live warehouse catalog. Search products, check delivery availability, add items to cart, place orders with supported payment options, and track order status from one simple shopping app.

Key features:

- EV spare parts catalog
- Product search and category browsing
- Cart and secure checkout
- COD and online payment support where available
- Delivery address and pincode support
- Order tracking and customer support
- Wishlist and repeat shopping shortcuts
